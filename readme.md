 🏠 SMART HOME AUTOMATION SYSTEM

 📌 Overview

The Smart Home Automation System is a Python-based, menu-driven application designed to simulate the automation and management of common household activities. It integrates multiple home management features into a single program, providing a simple and interactive way to control lighting, manage temperature settings, view weekly meal plans, operate household appliances, and simulate security monitoring.
The project demonstrates the practical application of core Python programming concepts, including functions, dictionaries, loops, conditional statements, input validation, file handling, and time-based operations.

 ✨ Features
1. Human Detection & Smart Lighting: Simulates human detection, automatically unlocks the door, turns on the lights, and adjusts light intensity according to the time of day.
2. Temperature Control: Provides options to simulate cold, normal, and hot temperature settings.
3. Weekly Kitchen Menu: Stores and displays breakfast, lunch, and dinner plans for all seven days of the week, including today's menu.
4. Home Appliances Management: Simulates the operation of a washing machine, dryer, television, dishwasher, and oven.
5. Security System: Simulates motion detection, alarm activation, and door unlocking.
6. Activity Logging: Records important system events with timestamps in a text file (`system_log.txt`).
7. Interactive Menu System:Uses nested menus to organize features and allow users to navigate between different modules.
8. Input Validation: Checks that menu inputs are numeric and handles invalid menu selections.

🛠️ Technologies Used:
1. Programming Language: Python
2. Modules: `time`
3. Data Structures: Dictionaries and variables
4. File Handling:Text file operations
5. Programming Concepts: Functions, loops, conditional statements, global variables, and input validation

How It Works:
1. Launch the program to access the main menu.
2. Select the human detection option to activate the simulated home automation features.
3. Choose a feature from the home control menu.
4. Interact with the available options to manage temperature settings, view meal plans, operate appliances, or access security features.
5. System events are recorded in `system_log.txt` for activity tracking.
6. Return to the main menu or turn off the system to exit.
